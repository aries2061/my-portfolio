# Aung Thura Portfolio

A responsive one-page portfolio built with Next.js 14.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Replace the sample headshot

Replace:

`public/headshot-placeholder.png`

with your own photo using the same filename, or update the image path in `app/page.js`.
